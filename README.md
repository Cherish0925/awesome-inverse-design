# Awesome Inverse Design [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)
> A curated list for engineers, physicists and hobbyists.

## General FDTD Engines & Optimizers
- [MEEP](https://github.com/NanoComp/meep): The classic FDTD engine for EM simulations from MIT.
- [BEAMZ](https://github.com/QuentinWach/beamz): Multi-physics FDTD and gradient-based optimization with Jax.
- [FDTDx](https://github.com/ymahlau/fdtdx): FDTD and inverse design with Jax.
- [Tidy3D](https://github.com/flexcompute/tidy3d): Flexcompute's API to define EM FDTD cloud-compute simulations and FDFD mode solver.
