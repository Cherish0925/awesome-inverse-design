# Awesome Inverse Design [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)
> A curated list for engineers, physicists and hobbyists.

## Tools
- [MEEP](https://github.com/NanoComp/meep): The classic FDTD engine for EM simulations from MIT.
- [BEAMZ](https://github.com/QuentinWach/beamz): Multi-physics FDTD and gradient-based optimization with Jax.
- [FDTDx](https://github.com/ymahlau/fdtdx): FDTD and inverse design with Jax.




- [EMopt](https://github.com/anstmichaels/emopt): Shape and topology optimization for 2D/3D EM structures using the adjoint method.
- [PhoTOS](https://github.com/aadityacs/PhoTOS): Topology optimization with shape libraries and VAE-based feature mapping for fabrication-aware photonic design.
- [NIDN](https://github.com/esa/NIDN): Neural inverse design of nanostructures with PyTorch, RCWA and FDTD forward models.


### [Shanhui Fan Group (Stanford)]()
- [Ceviche](https://github.com/fancompute/ceviche): Differentiable FDFD and FDTD simulator with autograd for gradient-based inverse design.
- [Legume](https://github.com/fancompute/legume): Guided-mode expansion for photonic crystal slabs with automatic differentiation.
- [Angler](https://github.com/fancompute/angler): Frequency-domain electromagnetic simulator with adjoint-based optimization.
- [S4](https://github.com/victorliu/S4): Stanford's rigorous coupled-wave analysis (RCWA) solver for layered periodic structures.
- [Tidy3D](https://github.com/flexcompute/tidy3d): Flexcompute's API to define EM FDTD cloud-compute simulations and FDFD mode solver.


### [Jelena Vuckovic Group (Stanford)](https://nqp.stanford.edu/research/heterogeneously-integrated-inverse-designed-photonics-optical-interconnects-computing)
- [SPINS-B](https://github.com/stanfordnqp/spins-b): Stanford's gradient-based photonic optimization library using FDFD.
